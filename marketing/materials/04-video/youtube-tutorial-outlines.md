# YouTube tutorial outlines

Format: screen recording with Keith's voice, 3 to 8 minutes each, plus a 60-second Short cut from each. Chapters on every video. Disclose at the top of the description: "I'm the creator of Church TV OS." Description links carry UTM tags (`utm_source=youtube&utm_medium=video&utm_campaign=launch2027&utm_content=pairing60s` and so on).
**Before recording:** make a fresh test church in the dashboard so the first-run screens are clean. Use your own original content, never copyrighted songs, curriculum or backgrounds. No children on camera.
**Record in this order:** 1 (pair), 2 (kids room), 3 (signage loop). Then the rest of the first-ten list in `../../03-marketing-strategy.md` section 5.

## Tutorial 1: Pair a TV in 60 seconds (Fire TV, Google TV, Roku)

**Title options:** "How to pair a TV with Church TV OS (Fire TV, Google TV, Roku)" · "Church TV OS: set up your first TV in 3 minutes"
**Search intent:** "how to put church videos on a fire tv", "fire stick for church setup"
**Length:** 3 to 4 minutes full; 60s Short.

| Chapter | Content | Screen |
|---|---|---|
| 0:00 Hook | "A six-character code is the whole setup." Show the end result first: a TV running a countdown. | TV |
| 0:20 What you need | A TV with an HDMI port; a Fire TV, Google TV or Roku device; a free account at app.churchtvos.com. Honest note: newer Fire TV sticks on Vega OS can't run it. | Talking head, then a quick shot of the devices |
| 0:50 Install the app | Search "Church TV OS" in the store: Fire TV (Appstore), Google TV (Play), Roku (Channel Store). `[Show the real store listings.]` | Each store |
| 1:30 The code | Open the app. The six-character code appears. Explain the optional Settings and demo mode (Menu on Fire TV; the Settings button on the pairing screen on Google TV). | TV |
| 2:00 Pair in the dashboard | app.churchtvos.com, Screens, Pair a TV, type the code, choose the location ("Main Room"), save. The church trial starts with a Main Room and 2 TVs. | Dashboard |
| 2:40 Show something | Add one text sign in Signage and see it appear. | Dashboard + TV |
| 3:10 If it doesn't work | Wrong code, no internet on the TV, an unsupported Vega OS stick, how to restart pairing. | Slides |
| 3:40 Next steps | "Next: your first kids room." Link to Tutorial 2. | End card |

**On-screen checklist:** Use the demo code from the pairing screenshot as an example only; do not reveal a real live code you intend to keep.

## Tutorial 2: Your first kids room (a playlist, a countdown, lyrics, scheduled for Sunday)

**Title options:** "How to run kids church videos on a TV without a laptop" · "Set up a kids room playlist in Church TV OS (countdown, lyrics, video)"
**Search intent:** "kids church video player", "sunday school video playlist", "church countdown timer for tv"
**Length:** 5 to 7 minutes; 60s Short cut of "schedule it Thursday".

| Chapter | Content | Screen |
|---|---|---|
| 0:00 Hook | The Sunday the video was on a laptop in the car. "Here's a Sunday that doesn't need a laptop." | Talking head + TV |
| 0:30 What a Kids playlist is | Videos, countdown, lyrics, YouTube link, pictures; the leader presses Play when ready. | Dashboard |
| 1:10 Add your video | Upload your own video (not a copyrighted curriculum video unless you're licensed to upload it). Licence reminder on screen. | Media page |
| 2:00 Add a countdown | Pick "Service starts in", time, what happens at zero. | Playlist editor |
| 2:45 Add song lyrics | Open the song library, paste lyrics, set the play order (verse, chorus, verse, chorus, bridge). Reminder: add only lyrics you're licensed to use. | Songs |
| 3:45 Put it in the room | Schedule for the room. Every Sunday, or a series with a weekly rotation. | Calendar |
| 4:45 Let the volunteer run it | Operator role; the phone remote: Next, Back, Blank. | Phone |
| 5:30 Offline | Unplug the Wi-Fi. It keeps playing. | TV |
| 6:00 Recap and next | Link to Tutorial 3. | End card |

**Honest notes to say aloud:** YouTube items work on Fire TV and Google TV but aren't supported on Roku. YouTube slides don't rotate on portrait screens. Church TV OS has no built-in curriculum library and no link to any curriculum company.
