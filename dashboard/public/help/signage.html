Signage module

Last updated 2026-10-20

The Signage module loops announcements on lobby and hallway screens. It plays by itself, on a weekly schedule, with no one needed at the TV.

Playlists

Open Signage, Playlists and press New playlist. Name it (for example "Lobby - Weekday loop"), then add items. They play in order and then start over.

What you can add

Image
Pick from your Signage library and choose how many seconds it shows.
Video
Plays to the end, then moves on.
Sign
A text-only slide made right in the dashboard, so you do not need a design tool. Enter a Title and optional smaller text, pick a background colour (including your church colours), choose left or centre alignment, set how many seconds it shows, and optionally show your church logo. The text colour is chosen for you so it stays readable. A preview shows landscape and portrait.
Live stream
A live video link ending in .m3u8 (HLS). Leave the time blank to keep it up until the playlist loops past it. See below.

Signs and live streams need the Church TV OS app version 1.1.0 or newer on the TV. A TV on an older version may not play a playlist that contains them. The version each TV runs is listed on the Screens page.

Live streams

  • Paste the HLS link (.m3u8) and press Test link. A failed test is only a hint, because many servers block browser checks.
  • Choose "If the stream is down": Skip it moves straight on so no room is left blank, or Show waiting for feed holds a card for a short while first, which suits a stream that starts a few minutes late.
  • Sound is off unless you turn on Play sound.

BoxCast

In BoxCast open the broadcast, choose Embed, and copy the Static M3U8 link into the stream box.

BoxCast viewers are about 30 to 40 seconds behind real life. That is fine for "watch the service" screens in the lobby, but do not use it for lyrics or anything that must match what is happening in the room.

Slots: when each playlist plays

A slot says which playlist plays on a screen (or a whole group) on certain days and times. Open Signage, Slots & schedule, choose a screen or group, and add slots, or add them on the Calendar. Slots repeat weekly.

  • If several slots overlap, the higher priority wins, then the newest.
  • When no slot is active, the screen plays its default playlist (set on the Screens page).
  • If there is no default playlist either, the screen shows a black screen. That is on purpose, so the TV is never showing something out of date.

Want the TV dark overnight? Do not add a slot for those hours and leave the default playlist empty. Or set the module schedule to Off.

Mixed TVs: Signage and Kids on the same screen

A screen only shows Signage when its module schedule says so (or when Signage is its default module). To run Signage on weekdays and Kids on Sunday, give the screen a module schedule: "Signage Monday to Saturday" and "Kids Sunday 8:00 to 13:00". Set this on the Screens page or the Calendar. Only owners and admins can change module schedules.

If a Signage playlist is not showing, check the module schedule first. A screen set to Kids at that time will not play Signage, however good the slot looks.
