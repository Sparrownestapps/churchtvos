Media library and folders

Last updated 2026-10-20

The media library is where your videos and images live. Upload a file once and use it in as many playlists as you like.

One library per application

Kids and Signage each have their own library. Open Kids, Media or Signage, Media in the left menu. A file uploaded to one is not available in the other, so upload it where you will use it. The header of each library shows how many files and how much space it uses.

Upload files

  1. Open the library. If you are inside a folder, files go into that folder.
  2. Drag videos or images onto the drop area, or click it to choose files. You can upload several at once.
  3. Watch the progress bar. Uploads are resumable, so a flaky Wi-Fi connection pauses rather than starts over.

Each new file is named after its file name. Use Rename to give it a friendlier title; playlists show that title.

Formats and sizes that work well

  • Videos: MP4 is the safest. 1080p (1920 by 1080) is plenty. Bigger 4K files are slow to download to a TV stick for no visible gain.
  • Images: JPG or PNG at 1920 by 1080 for landscape TVs, or 1080 by 1920 for portrait TVs.
  • Keep file sizes reasonable. If an upload is refused as too large, compress the video first, because there is a maximum file size on your storage plan.

Leave a little empty margin around text in images. Some TVs crop a few percent from the edges.

Folders

Use folders to keep a big library tidy, such as "Curriculum" then "Fall 2026".

  • + New folder creates one inside the folder you are viewing. Folders can nest.
  • Drag files onto a folder (or a name in the path at the top), or tick files and use Move to....
  • Switch between Grid and List views. The search box looks through the whole library, not only the current folder.
  • Deleting a folder is safe: its files and sub-folders move up one level. Nothing inside is deleted.

Sites and who can see a file

Each file, and each folder, is either available to All sites or limited to one site. You choose this with the site menu beside "Upload to". A folder limited to one site passes that limit on to everything inside it. People whose access is limited to certain sites can use only those sites' content. See People and roles.

Files in use are protected

If a file is in a playlist, the library shows Used in N playlists. Click it to see which ones. The dashboard will not let you delete a file that a playlist still uses, so a TV never ends up with a hole in its show. Remove the file from those playlists first, then delete it.

Deleting a file cannot be undone. If you only want to hide something for a while, move it to a folder named "Old" instead.
